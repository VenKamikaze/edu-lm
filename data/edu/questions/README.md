# Question packs

The `*.json` files in this directory are the shipped Edu-LM question packs. They are licensed under
[CC BY-SA 4.0](../../../LICENSE.CC-BY-SA-4.0). The curriculum codes in them belong to ACARA (CC BY 4.0),
attributed in the top-level README.

JSON has no comments, and unknown fields make the loader warn, so the licence lives here. Only
`*.json` files are installed and loaded; this file is neither.

The example pack `data/edu/examples/example-pack.json` has the same licence.

To add your own questions, see [docs/QUESTIONS.md](../../../docs/QUESTIONS.md).
